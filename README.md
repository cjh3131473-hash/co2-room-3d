## 측정 조건

- 측정 일시: 2026.11.11 18:14 – 21:16, 1분 간격 183회 (T&D TR-76Ui)
- 재실: 20대 남성 3명, 약 1시간 머문 뒤 전원 퇴실
- 개구부: 창문·현관문·화장실 문 모두 닫음
- 측정기 위치: 전자레인지 선반 위에서 두 번째 칸, 전기포트 옆 (바닥 위 약 0.65 m)
- 실 크기: 가로 2.55 m × 세로 5.20 m, 천장고 2.25 m, 주방 폭 1.20 m (실측) → 체적 약 32.3 m³

## 11주차 과제 Q1 · Q2

가정 (11주차 p.30): 외기 CO₂ 420 ppm, 재실자 1명당 CO₂ 발생량 0.018 m³/h, Build-up 때 침기량 = Q1, 완전혼합 (p.14)

**Q1. Decay 데이터로 공기교환율 n과 침기량 Q** — 방법: 11주차 p.29 예제4, p.30
(퇴실 때 문을 연 19:18–19:20의 일시 하락 뒤, 문을 닫은 뒤 첫 값 19:21을 0분으로 사용)

- 0분 19:21 → 2,394 ppm, 60분 20:21 → 2,136 ppm
- G = 0이므로 C(t) − Cᵢ = (C₀ − Cᵢ)e^(−nt) → n = ln[(2,394 − 420) / (2,136 − 420)] / 1 h = **0.140 회/h**
- Q = n·V = 0.140 × 32.3 = **4.5 m³/h** (시정수 τ = 1/n = 7.1 h, p.22 · 반감기 0.693/n = 4.9 h, p.21)
- 신축 공동주택 기준 0.5 회/h(p.9)의 28%

**Q2-1. Build-up 최고 2,508 ppm → 1,000 ppm(p.4) 초과** — 방법: 11주차 p.20 정상상태, p.19 단위 환산
3명이 계속 머물러도 정상상태에서 1,000 ppm 이하가 되려면

- Css = Ci + G/Q ≤ 1,000 ppm, G = 3 × 0.018 = 0.054 m³/h
- Q ≥ 0.054 / (580 × 10⁻⁶) = **93.1 m³/h** (n = 2.89 회/h, 1인당 31 m³/h → p.10의 29–36 m³/h·인 범위)
- 현재 침기량의 약 21배. 틈새바람만으로 계속 머물면 정상상태 농도는 약 12,400 ppm

- 방 안 기류의 방향과 속도(창·현관 쪽 하강, 가운데·재실자·냉장고 위 상승, 천장을 따라 되돌아감). 강의의 완전혼합 가정(p.14)과 "따뜻한 공기는 위로"(10주차 p.13)를 그림으로 보이기 위한 것이며, 실제보다 빠르게 움직임
