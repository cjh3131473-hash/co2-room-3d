## 측정 조건

- 측정 일시: 2026.11.11 18:14 – 21:16, 1분 간격 183회 (T&D TR-76Ui)
- 재실: 20대 남성 3명, 약 1시간 머문 뒤 전원 퇴실
- 개구부: 창문·현관문·화장실 문 모두 닫음
- 측정기 위치: 전자레인지 선반 위에서 두 번째 칸, 전기포트 옆 (바닥 위 약 0.65 m)
- 실 크기: 가로 2.55 m × 세로 5.20 m, 천장고 2.25 m, 주방 폭 1.20 m (실측) → 체적 약 32.3 m³

## 11주차 과제 Q1 · Q2

가정: 외기 CO₂ 420 ppm, 재실자 1명당 CO₂ 발생량 0.018 m³/h, Build-up 때 침기량 = Q1, 완전혼합

**Q1. Decay 데이터로 공기교환율 n과 침기량 Q**
(퇴실 때 문을 연 19:18–19:20의 일시 하락 뒤, 문을 닫은 뒤 첫 값 19:21을 0분으로 사용)

- 0분 19:21 → 2,394 ppm, 60분 20:21 → 2,136 ppm
- n = ln[(2,394 − 420) / (2,136 − 420)] / 1 h = **0.140 회/h**
- Q = n·V = 0.140 × 32.3 = **4.5 m³/h** (시정수 7.1 h, 반감기 4.9 h)
- 확인: 감소 구간 전체 회귀 n = 0.158 회/h (R² 0.999)

**Q2-1. Build-up 최고 2,508 ppm → 1,000 ppm 초과**
3명이 계속 머물러도 정상상태에서 1,000 ppm 이하가 되려면

- Css = Ci + G/Q ≤ 1,000 ppm, G = 3 × 0.018 = 0.054 m³/h
- Q ≥ 0.054 / (580 × 10⁻⁶) = **93.1 m³/h** (n = 2.89 회/h, 1인당 31 m³/h)
- 현재 침기량의 약 21배. 틈새바람만으로 계속 머물면 정상상태 농도는 약 12,400 ppm

## 공기 흐름 추정 방법

- 실내: 질량보존을 만족하는 유선함수로 만든 2셀 자연대류(차가운 창·현관문 쪽 하강 → 바닥을 따라 가운데로 → 상승 → 천장을 따라 되돌아감)와 재실자·냉장고 위 열기둥
- 실외와의 교환: 실내외 온도차(굴뚝효과)에 의한 중성대 위 누기, 아래 침기
- CO₂ 입자 수는 측정 농도에 비례. 재생하면 재실자 입에서 생기고 틈으로 빠져나감

틈새바람 경로, 중성대 높이, 재실자 위치는 압력차 원리에 따른 추정이며 측정값이 아닙니다.
